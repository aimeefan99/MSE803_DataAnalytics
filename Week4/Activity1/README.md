# Week 4 - Activity 1: Happiness Dashboard and Data Visualisation

This activity creates a simple happiness dashboard using the provided `world_happiness_dataset.csv`.

## Files

- `world_happiness_dataset.csv`: source dataset provided for the activity
- `happiness_dashboard.py`: dashboard and visualisation script
- `report_template.md`: markdown template used to generate the report
- `dashboard_report.md`: generated report with findings
- `cleaned_world_happiness_dataset.csv`: cleaned dataset generated by the script
- `outputs/`: generated Matplotlib PNG charts and Plotly HTML charts
- `requirements.txt`: required Python packages

## How to Run

From `Week4/Activity1`:

```bash
python -m pip install -r requirements.txt
python happiness_dashboard.py
```

## Visualisation Libraries Used

- `matplotlib`: static PNG charts
- `plotly`: interactive HTML dashboard charts
