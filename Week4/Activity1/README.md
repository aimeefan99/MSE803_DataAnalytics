# Week 4 - Activity 1.2: Happiness Dashboard, Data Visualisation, and Outlier Detection

This activity updates the happiness dashboard using the provided `world_happiness_dataset.csv` and adds IQR-based outlier detection.

## Files

- `world_happiness_dataset.csv`: source dataset provided for the activity
- `happiness_dashboard.py`: data cleaning, analysis, outlier detection, and visualisation script
- `dashboard_report.md`: written report with dashboard findings
- `outlier_detection_report.md`: written explanation for Activity 1.2 outlier detection
- `cleaned_world_happiness_dataset.csv`: cleaned dataset generated by the script
- `outputs/`: generated Matplotlib PNG charts and Plotly HTML charts
- `requirements.txt`: required Python packages

## How to Run

From `Week4/Activity1`:

```bash
python -m pip install -r requirements.txt
python happiness_dashboard.py
```

## Visualisation Libraries Used

- `matplotlib`: static PNG charts
- `plotly`: interactive HTML dashboard charts
