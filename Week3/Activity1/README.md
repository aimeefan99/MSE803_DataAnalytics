# Week 3 - Activity 1: Initial Statistical Analysis

Repository link: https://github.com/aimeefan99/MSE803_DataAnalytics

## Understanding

This activity performs an initial statistical analysis on `Sample_dataset.csv`.
Before calculating statistics, the dataset is cleaned because it contains
missing values, duplicate IDs, inconsistent country codes, text values in
numeric columns, and invalid dates.

The dataset is treated as a sample, not a full population. Therefore sample
variance, sample standard deviation, and sample covariance are calculated with
sample-based calculations.

## Files

- `Sample_dataset.csv`: original dataset supplied for the activity
- `initial_statistical_analysis.py`: Python analysis script
- `cleaned_dataset.csv`: cleaned dataset generated by the script
- `analysis_results.md`: generated output and metric explanations
- `requirements.txt`: Python packages required to run the script

## Libraries Used

- `pandas`: data loading, cleaning, and type conversion
- `numpy`: statistical metrics required by the activity

References:

- NumPy statistics routines: https://numpy.org/doc/2.5/reference/routines.statistics.html
- pandas `DataFrame.describe()`: https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.describe.html

## Data Cleaning Decisions

- Kept rows with missing `ID` when their analytical fields were still useful.
- Merged duplicate records with the same `ID` when values were complementary.
- Converted `Age`, `Net worth`, and `Salary` to numeric values.
- Removed thousands separators, for example `30,000`.
- Converted simple text numbers, for example `thirty-eight` and
  `sixty five thousand`.
- Kept missing numeric values as `NaN` and ignored them during statistical
  calculations.
- Standardised `Country` values by converting `AU` to `AUS` and filling empty
  country values as `Unknown`.
- Parsed valid join dates and corrected Eve's date from `2019-13-01` to
  `13/01/2019`.

## Metrics Calculated

- `mean`: arithmetic average
- `sample variance`: spread of values around the mean
- `sample standard deviation`: square root of sample variance
- `sample covariance`: whether two variables move together

## How to Run

From the repository root:

```bash
python3 -m pip install -r Week3/Activity1/requirements.txt
python3 Week3/Activity1/initial_statistical_analysis.py
```

The script prints the results and writes them to
`Week3/Activity1/analysis_results.md`.
