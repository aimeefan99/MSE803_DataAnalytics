# Week 5 - Activity 1: SVM Classification on Iris Dataset

This activity classifies the Iris dataset using a Support Vector Machine (SVM) classifier from scikit-learn.

## Files

- `iris_svm_classification.py`: main analysis script
- `iris/`: local Iris dataset files kept for reference
- `cleaned_iris_dataset.csv`: cleaned dataset generated by the script
- `outputs/`: generated model results and visualisations
- `svm_classification_report.md`: written explanation of method and findings

## How to Run

From `Week5/Activity1`:

```bash
conda activate 803env
python iris_svm_classification.py
```

## Main Outputs

- `outputs/svm_model_accuracy.csv`
- `outputs/svm_classification_report.csv`
- `outputs/svm_confusion_matrix.csv`
- `outputs/iris_petal_scatter.png`
- `outputs/svm_confusion_matrix.png`
